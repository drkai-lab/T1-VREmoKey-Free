Unity 2022 draws editor text with a Latin font that has no Hangul. The
profile window uses an OS font that contains Hangul when one is installed
(Malgun Gothic, Apple SD Gothic Neo, Noto Sans CJK KR, and the other names
in EditorLocale). This file is the fallback when none of those fonts exist.
